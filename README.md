## 매치그리드로 할 수 있는 일

- **내 경기 캘린더** — 관심 팀이나 리그를 선택하면 해당 경기만 월간 달력에 표시됩니다. 날짜를 누르면 대진과 시작 시간을 확인할 수 있습니다.
- **홈 화면 위젯** — 앱을 열지 않아도 월간 일정을 보고, 날짜를 눌러 경기 목록으로 이동할 수 있습니다.
- **다음 경기까지 남은 시간** — 관심 일정 중 가장 가까운 경기의 시작 시각과 남은 시간을 보여줍니다.
- **자동 동기화** — 공개 일정을 약 6시간마다 갱신합니다. 바로 새로고침하려면 **설정 → 일정 동기화**를 누르세요.

## 처음 사용하기

1. Android 기기에 위 APK를 설치합니다.
2. 앱의 **설정 → 관심 종목 및 팀**에서 팀이나 리그를 선택합니다. 선택하기 전에는 빈 달력이 보입니다.
3. 홈 화면에 위젯을 추가하려면 빈 공간을 길게 누르고 **위젯 → 매치그리드**를 선택합니다.

## 앱 업데이트

1.4.2부터는 **설정 → 업데이트 확인**으로 새 버전을 받을 수 있습니다. 앱은 다운로드한 APK의 파일 크기, SHA-256, 패키지 ID, 버전, 서명을 확인하고 Android 설치 화면을 안내합니다.
